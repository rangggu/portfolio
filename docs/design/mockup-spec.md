# 캔버스 시안 스펙 (임시 디자인)

시각 디자인이 확정되기 전까지 화면 구성에 쓰는 임시 기준이다. 값은 시안(`docs/design/mockup/*.dc.html`)에서 뽑았다. 시안 파일은 디자인 도구용 형식이라 구조와 수치를 참고하는 용도로만 쓰고, 코드는 기존 컨벤션(CSS Modules, 토큰, 컴포넌트)으로 새로 작성한다.

라이트 모드 기준이다. 다크 모드 값은 시안에 없으므로 같은 대비 관계를 유지하도록 정한다.

## 글꼴

- 본문: Pretendard (시안은 Noto Sans KR로 대신 그렸음)
- 고정폭: 시안은 IBM Plex Mono. 프레임 이름표, 연도, 섹션 번호, 기간 표기에 쓰임. 우선 `--font-family-mono`(시스템 고정폭)로 구현하고, 별도 글꼴 도입은 나중에 판단

## 캔버스와 프레임

- 프레임: 흰 배경, 1px 테두리, 모서리 없음(radius 0), 아주 옅은 그림자 `0 2px 6px rgba(27, 30, 35, 0.05)`
- 프레임 이름표: 프레임 위 왼쪽, 고정폭 12px, 보조 글자 색. 예: `01 소개 · /about`
- 현재 프레임(선택 상태): 1.5px 포인트색 외곽선 + 네 모서리에 8×8px 흰 사각형 핸들(1.5px 포인트색 테두리, 모서리에서 -5px). 이름표도 포인트색
- 옆 프레임: 선택 표시 없이 테두리만

## 플로팅 UI (데스크톱)

공통: 흰 배경, 그림자 `0 1px 2px rgba(27,30,35,0.06), 0 6px 20px rgba(27,30,35,0.08)`, 화면 가장자리에서 20px

| 위치        | 구성                                                                                       | 크기                                                                                                                                                                            |

## 플로팅 UI (모바일, 터치)

- 위쪽: 화면 좌우 12px 안쪽의 한 줄 바, 높이 52px, 모서리 14px. 왼쪽에 아이콘 + "Myu" + "/ 현재 프레임", 오른쪽에 물어보기·테마 아이콘 버튼(44px)
- 아래쪽: 좌우 12px, 아래 16px 안쪽의 메뉴 바, 높이 56px, 모서리 14px. 항목이 넘치면 가로로 밀어서 보기

## 프레임 안 공통

- 섹션 머리: 위쪽 1px 본문색 구분선, 그 아래 고정폭 번호(13px, 약한 글자) + 제목(32px, 700, 자간 -0.02em). 번호와 제목 사이 14px
- 안쪽 여백: 시안은 위아래 64px, 좌우 56px (지금 구현의 토큰 규칙에 맞춰 조정 가능)

## 첫 화면

- 2열: 왼쪽 내용 + 오른쪽 280px 연락처 블록, 열 간격 64px, 아래 정렬
- 이름 72px / 700 / 자간 -0.035em, 옆에 직무 22px 보조 글자 (기준선 맞춤)
- 한 줄 소개 40px / 700 / 자간 -0.025em
- 보조 문장 18px / 줄 간격 1.7 / 보조 글자
- 연락처 블록: 위쪽 1px 본문색 구분선, 행마다 왼쪽 고정폭 라벨(12px) + 오른쪽 값(14px), 행 간격 14px. 이메일 · GitHub · 개발 시작

## 소개 (여백 메모)

- 본문 18px / 줄 간격 1.85, 문단 간격 24px
- 메모: 흰 배경, 1px 테두리, 모서리 12px, 패딩 16px 18px. 위에 고정폭 "메모" 라벨(11px), 본문 14px / 줄 간격 1.7
- 강조 상태: 메모 테두리와 라벨이 포인트색, 연결 텍스트에 포인트 옅은 배경
- 연결 텍스트: 1.5px 점선 밑줄 (기본은 회색, 강조 시 포인트색)

## 경력 (두 갈래 타임라인)

- 열: 연도 80px | 회사 레인 3fr | 사이드 레인 2fr, 열 간격 32px
- 머리줄: 회사(6px 굵은 막대 표시) / 사이드·개인(2px 선 표시), 고정폭 12px
- 연도 행마다 위쪽 1px 구분선, 연도는 고정폭 15px. 지금 보는 연도는 포인트색 + 7px 점
- 회사 레인: 6px 본문색 막대(시작 행은 위쪽 둥근 모서리), 회사명 20px / 700, 역할·기간 고정폭 13px, 성과 16px (수치 부분만 500)
- 사이드 레인: 2px 회색 선, 이름 16px / 500, 기간 고정폭 12px. 교육 과정 시기 항목은 투명도 0.6
- 사이드 레인 마지막: "이 포트폴리오" + 포인트색 "지금 보는 중"

## 프로젝트 · 기술 · 학력·자격 · 연락처

- 프로젝트: 행 목록(번호 56px | 제목·요약 | 메타 | 화살표), 행 높이 최소 120px, 아래 구분선. 제목 22px / 700, 요약 16px 보조 글자
- 기술: 4열 그리드, 분류 라벨 고정폭 12px, 항목마다 아래 구분선, 오른쪽에 첫 사용 시점
- 학력·자격: 2열, 행마다 이름(17px) + 오른쪽 연도(고정폭 13px)
- 연락처: 26px / 500 문장 + 버튼 3개(이메일 복사, GitHub, 이력서 인쇄), 버튼 높이 48px, 모서리 10px
