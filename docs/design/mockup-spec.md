# 캔버스 시안 스펙 (임시 디자인)

시각 디자인이 확정되기 전까지 화면 구성에 쓰는 임시 기준이다. 값은 시안(`docs/design/mockup/*.dc.html`)에서 뽑았다. 시안 파일은 디자인 도구용 형식이라 구조와 수치를 참고하는 용도로만 쓰고, 코드는 기존 컨벤션(CSS Modules, 토큰, 컴포넌트)으로 새로 작성한다.

라이트 모드 기준이다. 다크 모드 값은 시안에 없으므로 같은 대비 관계를 유지하도록 정한다.

## 글꼴

- 본문: Pretendard (시안은 Noto Sans KR로 대신 그렸음)
- 고정폭: 시안은 IBM Plex Mono. 프레임 이름표, 연도, 섹션 번호, 기간 표기에 쓰임. 우선 `--font-family-mono`(시스템 고정폭)로 구현하고, 별도 글꼴 도입은 나중에 판단

## 캔버스와 프레임

- 프레임: 흰 배경, 1px 테두리, 모서리 없음(radius 0), 아주 옅은 그림자 `0 2px 6px rgba(27, 30, 35, 0.05)`
- 프레임 이름표: 프레임 위 왼쪽, 고정폭 12px, 보조 글자 색. 예: `01 소개 · /about`
- 현재 프레임(선택 상태): 1.5px 포인트색 외곽선 + 네 모서리에 8×8px 흰 사각형 핸들(1.5px 포인트색 테두리, 모서리에서 -5px). 이름표도 포인트색
- 옆 프레임: 선택 표시 없이 테두리만

## 플로팅 UI (모바일, 터치)

- 위쪽: 데스크톱과 같은 두 상자. 오른쪽은 테마 · 더보기만 (터치는 스와이프 하나라 모드 전환이 없음)
- 아래쪽: 좌우 12px, 아래 16px 안쪽의 메뉴 바, 높이 56px, 모서리 14px. 항목이 넘치면 가로로 밀어서 보기

## 프레임 안 공통

- 섹션 머리: 고정폭 번호(13px, 약한 글자) + 제목(32px, 700, 자간 -0.02em). 번호와 제목 사이 14px. 위쪽 구분선은 없음 (PORTFOLIO-19에서 뺌: 프레임 테두리와 겹치고, 진한 선은 묶음 이름 밑에 씀)
- 안쪽 여백: 시안은 위아래 64px, 좌우 56px (지금 구현의 토큰 규칙에 맞춰 조정 가능)

## 첫 화면

PORTFOLIO-31에서 바꿈: 이름이 크고 대표 문구가 작은 2열 + 연락처 블록 → 대표 문구가 주인공인 2열 + 「1px까지 본다」 그림. 연락처는 연락처 프레임·오른쪽 위 더보기가 맡는다.

- 2열(1.15 : 1, 열 간격 48px, 세로 가운데): 왼쪽 문구, 오른쪽 그림
- 제목(h1): 「이름 · 직무」 15px / 500 보조 글자 (직무는 400)
- 대표 문구: display(48→72px) / 700, 보조 문장: bodyLg 보조 글자, 최대 폭 32rem
- 그림(HeroVisual, 장식이라 보조기기에서 숨김): 최대 400px 카드(이미지 · 제목 · 설명 · 포인트색 버튼)에 캔버스 선택 표시(포인트색 테두리 + 네 모서리 핸들)와 이름표 「Card · 400 × 352」, 안쪽 여백 24를 점선·배지로 측정. 지름 204px 돋보기가 카드 왼쪽 모서리를 키워 제목 줄과 버튼의 왼쪽 끝이 한 칸(1px) 어긋난 것을 안내선과 포인트색 「1px」 배지로 보여 준다

## 소개 (여백 메모)

- 본문 18px / 줄 간격 1.85, 문단 간격 24px
- 메모: 흰 배경, 1px 테두리, 모서리 12px, 패딩 16px 18px. 위에 고정폭 "메모" 라벨(11px), 본문 14px / 줄 간격 1.7
- 강조 상태: 메모 테두리와 라벨이 포인트색, 연결 텍스트에 포인트 옅은 배경
- 연결 텍스트: 1.5px 점선 밑줄 (기본은 회색, 강조 시 포인트색)

## 경력 (두 갈래 타임라인)

- 열: 연도 80px | 회사 레인 3fr | 사이드 레인 2fr, 열 간격 32px
- 머리줄: 회사(6px 굵은 막대 표시) / 사이드·개인(2px 선 표시), 고정폭 12px
- 연도 행마다 위쪽 1px 구분선, 연도는 고정폭 15px. 지금 보는 연도는 포인트색 + 7px 점
- 회사 레인: 6px 본문색 막대(시작 행은 위쪽 둥근 모서리), 회사명 20px / 700, 역할·기간 고정폭 13px, 성과 16px (수치 부분만 500)
- 사이드 레인: 2px 회색 선, 이름 16px / 500, 기간 고정폭 12px. 교육 과정 시기 항목은 투명도 0.6
- 사이드 레인 마지막: "이 포트폴리오" + 포인트색 "지금 보는 중"

## 프로젝트 · 기술 · 학력·자격 · 연락처

- 프로젝트: 행 목록(번호 56px | 제목·요약 | 메타 | 화살표), 행 높이 최소 120px, 아래 구분선. 제목 22px / 700, 요약 16px 보조 글자
- 기술: 분류 카드 4열 × 2줄(분류 8개, 간격 가로 24px · 세로 32px, 중간 폭은 2열). 카드는 둥근 모서리 16px · 테두리 없이 바탕색만(프레임 바탕에 글자색 4%를 섞어 라이트는 아주 연한 회색, 다크는 한 단계 밝게), 안쪽 여백 32px, 굵은 분류 이름 아래 20px 띄워 기술 이름 칩(Tag, 바탕은 프레임 바탕에 글자색 9%를 섞어 카드보다 한 단계 더 · 테두리 없음, 여백 6px 12px, 칩 간격 가로 8px · 세로 12px)이 줄바꿈. 좁으면 카드 한 열 (PORTFOLIO-32에서 분류 5개 4열 · 진한 선 · 줄 목록 · 첫 사용 시점 → 분류 8개 카드 + 칩: 선 목록은 딱딱하고 길어서, 분류는 협업·배포·분석이 한 칸에 섞여서)
- 학력·자격: 2열, 행마다 왼쪽 날짜 열(고정폭 13px) + 이름(17px)·세부 (PORTFOLIO-19에서 오른쪽 연도 → 왼쪽 날짜 열로 바꿈: 넓으면 이름과 날짜가 너무 멀어서). 묶음 이름(학력·자격)은 굵은 제목 + 아래 1px 본문색 선
- 연락처: 마지막 화면이라 한 덩어리를 프레임 가운데(가로·세로)에. 인사 문장(headingLg) → 넓은 간격(48px) → 「라벨 · 값」 연락처 묶음(이메일, GitHub, 줄 사이 12px). 값을 누르면 복사되고(메일 앱·새 탭을 열지 않음) 끝의 작은 복사 아이콘이 그 표시. 묶음은 가운데, 줄은 라벨 열 | 값 열로 왼쪽 정렬. 「연락처」 제목은 이름표·메뉴 바와 겹쳐 보조기기에만. 이력서 인쇄는 오른쪽 위 더보기에만 (PORTFOLIO-19에서 버튼 3개 → 가운데 한 덩어리)
